# DOSMIL 2000 — E-Commerce Concept Redesign

An independent e-commerce redesign & portfolio concept for **DOSMIL** ([dosmil2000.com](https://www.dosmil2000.com/)), an autonomous Philippine streetwear label and home of the Twoface community (Est. 2020, Manila, PH).

> **Disclaimer**: This project is an independent design & engineering portfolio concept and is not the official brand website of DOSMIL. All trademarks, logos, video assets, and product photography belong to DOSMIL.

---

## ⚡ Key Features

- **Brutalist Underground Aesthetic**: Custom typography (`Anton`, `Space Grotesk`, `Space Mono`), stark contrast borders, and grain-textured layouts inspired by Manila underground skate & streetwear culture.
- **Authentic Asset Integration**: Official header logo, Twoface mask mark, and high-definition looping hero video directly referenced from DOSMIL's brand media.
- **Complete Product Catalog**: 29 live DOSMIL items across drops (Halloween Drop, Milligans, Utility Shorts, Heavy Fleece Hoodies, 220 GSM Tees) with multi-angle photo previews.
- **Interactive Product Modal**: Sized 400px contained views with interactive size selection (S to 2XL), responsive bottom thumbnail strip, and size chart modal.
- **Streetwear Size Chart**: Heavyweight 220 GSM and 420 GSM boxy-fit measurement guides.
- **Twoface Story Archive**: Curated video cards streaming official campaign BTS and anniversary documentaries directly with real thumbnail overlays.
- **Fast Cash on Delivery (COD) Checkout**: Frictionless nationwide checkout form tailored for Philippine buyers with simulated order confirmation & reference receipt.
- **Twoface Run Club RSVP**: Interactive community run club registration for Thursday Eastwood sessions.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Vanilla CSS (Modular design tokens, brutalist streetwear grid system)
- **Icons**: Lucide React
- **Fonts**: Anton, Space Grotesk, Space Mono, Syne (Google Fonts)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/<your-username>/dosmil-concept.git

# Navigate to project directory
cd dosmil-concept

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Building for Production

```bash
npm run build
```

The compiled output will be generated inside the `dist/` directory, ready for deployment to **Vercel**, **Netlify**, or **GitHub Pages**.
